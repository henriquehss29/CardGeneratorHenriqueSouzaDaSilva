# 🎯 Gerador de Cartões de Crédito

**Projeto de POO - Henrique Souza da Silva**  
*Curso Técnico em Tecnologia da Informação*

## 📋 Sobre o Projeto

Este projeto foi desenvolvido como trabalho prático da disciplina de Programação Orientada a Objetos. 

## 🚀 Funcionalidades

- ✅ Geração de cartões válidos (Visa, Mastercard, Amex, Elo)
- ✅ Validação usando algoritmo de Luhn
- ✅ Interface web para interação
- ✅ API REST para integração

## 🎮 Como Usar

1. Execute a aplicação
2. Acesse a URL mostrada no console
3. Escolha a bandeira e digite o nome
4. Clique em "Gerar Cartão"

## 🧮 Algoritmo de Luhn para Cartões

O projeto implementa corretamente o algoritmo de Luhn para validação de cartões de crédito, garantindo que todos os números gerados sejam válidos.
